# Состояние USB-выпуска

Подготовлены EZCH Update 1.5.1 r19 и единый EZCH Launcher USB 0.15. В одном Launcher APK находятся рабочий стол, обновления, установка локальных APK и файловый менеджер. Начальная настройка открывает системные разрешения из приложения.

| Возможность | Состояние |
| --- | --- |
| Рабочий стол 0.11/0.12 | Исходная компоновка, фон, логотип и верхние кнопки из архива пользователя |
| Живые обои | Встроенное движение космоса и выбор локального видео; остановка вне HOME, возврат и резервный фон |
| Glass UI, вариант 3 | Реализован в карточках ТВ/HDMI/AV/USB |
| Подсветка подключения | Системные события, мягкое свечение, усиление при новом подключении и затухание при отключении |
| Перемещение и скрытие приложений | Реализовано, настройки сохраняются |
| Короткое Home | Возвращение в начало и закрытие меню |
| Долгое Home / OK | Home через доступную службе кнопку; OK открывает меню внутри лаунчера |
| Файловый менеджер | Системный выбор папки, открытие, копирование, проверка копии, перемещение, переименование, удаление с подтверждением |
| Установка и обновления | Проверка APK, системное согласие, журнал, восстановление, точные итоги |
| Первый запуск без сети | Встроенный каталог, резерв при повреждённом кэше |
| GitHub | Исходники, воспроизводимая сборка, проверки, готовые подписанные файлы выпуска |
| Переписки | Локальный частный архив на компьютере, отдельно от публичного репозитория |
| Физический ТВ и Play Protect | Ещё не проверены: устройства отсутствуют в этой среде |

Пакет нового Launcher отличается от прежнего HomeEZCH, чтобы не удалять старую установку и не зависеть от недоступного прежнего ключа. Standalone EZCH Update сохраняет оригинальную подпись. Предыдущие GitHub-коммиты и выпуск 1.4 остаются доступными для восстановления.

Доступ к системным папкам, роль домашнего экрана и события физических входов определяются Android и прошивкой ТВ. Установочный комплект не требует отключать штатный лаунчер командами или обходить защиту.
