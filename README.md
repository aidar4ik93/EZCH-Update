# EZCH — установка с USB

**EZCH Launcher USB 0.20** объединяет рабочий стол, EZCH Update и файловый менеджер в одном APK. **EZCH Update 1.6.2 (r23)** также доступен отдельным приложением. Android 8.0+ (API 26), Android TV и Google TV.

[Скачать готовый комплект и APK](https://github.com/aidar4ik93/EZCH-Update/releases/latest) · [Проверки](TESTING.md) · [Состояние проекта](PROJECT_PLAN.md)

## Установка на телевизор

1. Скопируйте `EZCH_Launcher_0.20_USB.apk` на флешку и установите его через файловый менеджер телевизора.
2. Откройте **EZCH Launcher USB**. Начальный экран приложения предлагает выбрать его домашним экраном и настроить кнопку Home.
3. Откройте **EZCH Store** — встроенный EZCH Update, выберите приложения пультом и нажмите «Установить выбранные». Android один раз попросит разрешение установки из этого источника и затем подтверждение каждой установки.
4. Встроенный **Файловый менеджер** открывает внутреннюю память и USB после разрешения Android. Кнопка «Выбрать папку / USB» предоставляет альтернативный доступ через системный выбор папки. Можно открывать файлы, устанавливать APK, создавать папки, копировать, перемещать, переименовывать и удалять. Перед перемещением проверяется SHA-256 копии; существующие файлы не перезаписываются. Альтернативный доступ через выбор папки копирует отдельные файлы до 1 ГБ.

Команды, ADB, отдельный установщик и отдельный файловый менеджер для работы установленного приложения не требуются. Android сам управляет разрешениями: приложение открывает необходимые системные окна, но не может подтвердить их за пользователя. Для загрузки приложений из каталога нужен интернет. Без сети открывается сохранённый или встроенный список; локальные APK можно выбирать с USB.

Сборка Launcher имеет отдельный пакет `com.example.homeezch.usb` и устанавливается рядом с прежним HomeEZCH. Это позволяет сохранить прежнюю установку и выбрать новый домашний экран. EZCH Update 1.6.2 продолжает ветку рабочего тестового приложения: пакет `com.example.ezchupdate.tvtest`, обычное название без «Тест». Ключ тестовой 1.5 недоступен, поэтому первая установка 1.6.1 требует удаления тестовой 1.5 после сохранения данных. Выпуск подписан постоянным доступным ключом EZCH; последующие обновления совместимы. Старый отдельный Update исключён из активного каталога.

В Update кнопка «Установить лаунчер» проводит загрузку, разрешение и подтверждение Android, затем открывает рабочий стол. Store запускает установленный Update 1.6.2; без него работает встроенный магазин. Android запрашивает выбор домашнего экрана самостоятельно.

## Скорость и устойчивость

Магазин сразу показывает проверенный локальный список и обновляет его в фоне: медленная сеть не блокирует выбор приложений. При обычном возврате проверка каталога выполняется не чаще одного раза в пять минут; кнопка «Проверить обновления» запрашивает его вручную. Значки установленных приложений загружаются вне основного потока. Лаунчер обновляет анимацию ореола на этапе рисования, без пересборки всей карточки на каждом кадре. Координаты плавающего меню не вызывают перерисовку всего рабочего стола при прокрутке.

Открытие лаунчера после установки проверяет, что установлена именно запрошенная версия. Карточки магазина получили более мягкие углы, заголовок показывает число выбранных приложений и фоновую проверку. Меню удержания стало компактнее и прозрачнее.

## Рабочий стол и разъёмы

Удержание OK на карточке открывает полупрозрачное меню над ней: «Переместить приложение» и «Скрыть с рабочего стола». Стрелками выберите действие, коротким OK подтвердите. После перемещения новое удержание снова открывает оба пункта; удержание во время перемещения возвращает меню. Назад закрывает меню или отменяет перемещение. Скрытие убирает карточку с рабочего стола, приложение остаётся установленным.

- Компоновка и исходные изображения восстановлены из `EZCH_Launcher_0.12_QA_Source.zip`: часы и погода слева, исходные верхние кнопки и логотип. Изменено оформление разъёмов.
- Космический фон и выбранный вариант **3 — Glass UI**: полупрозрачные стеклянные карточки ТВ, HDMI, AV и USB. HDMI 2 выделен тёплым цветом.
- Подключённый источник мягко подсвечивается. Новое подключение плавно усиливает свечение, затем оно возвращается к спокойному уровню; отключение плавно гасит фон карточки. Фокус пульта имеет отдельную рамку.
- Состояние HDMI/AV приходит из `TvInputManager`, USB — из системных событий устройств и накопителей. Если прошивка скрывает источник или его состояние, карточка сообщает, что состояние неизвестно. Такие карточки не изображают подключение.
- USB открывает список обнаруженных накопителей и встроенный файловый менеджер. USB-устройства объединены в одну карточку; число накопителей берётся из Android.
- Долгое OK на приложении открывает перемещение и скрытие. Порядок и скрытые приложения сохраняются; скрытые доступны через «Все приложения».
- Короткое Home возвращает к началу рабочего стола. Долгое Home открывает действия приложения, если телевизор передаёт эту кнопку включённой службе специальных возможностей. Долгое OK доступно без перехвата Home.

Некоторые телевизоры запрещают сторонний домашний экран или не передают Home/состояния HDMI сторонним приложениям. Физическая проверка на конкретном ТВ обязательна; эмулятор не подтверждает поведение разъёмов и Google Play Защиты.

Начиная с 0.16 выбранное приложение плавно увеличивается и получает мягкий световой ореол с тонким контуром. Настройки EZCH представлены карточками с иконками, пояснениями, разделами и текущими состояниями.

## Живые обои

Откройте «Настройки» → «Живые обои · Космос» для встроенного плавного движения фона либо «Выбрать видеообои / USB» для своего видео. Видео без звука повторяется на рабочем столе, освобождает проигрыватель при выходе и восстанавливается при возвращении. При недоступном файле, ошибке декодирования или отсутствии первого кадра за 12 секунд остаётся исходный космический фон.

Режим «Авто» включает чёрный Lite на устройствах с малым объёмом памяти и при энергосбережении. В Premium сохраняется космическое оформление; при перегреве или нехватке памяти движение и видео приостанавливаются. Настройки порядка, строк, скрытых приложений и Lite из USB 0.13 переносятся при обновлении. Еженедельная уборка удаляет только устаревшие файлы погоды самого лаунчера, не останавливая VPN, TorrServe и другие приложения.

## Каталог и установка

`apps.json` загружается из ветки main. Файлы сторонних приложений скачиваются из указанной папки Google Drive без входа в Google; ссылки относятся к отдельным APK. Собственные новые выпуски EZCH остаются на GitHub Releases. Копии в `app/src/main/assets/apps.json` и `launcher/app/src/main/assets/apps.json` используются без сети. Проверяются пакет, версия, размер, SHA-256 APK и сертификат подписи. Установщик использует системное подтверждение, журнал сеансов и восстановление очереди после перезапуска. Самообновление выполняется последним.

Автоматическая синхронизация [Google Drive](https://drive.google.com/drive/folders/1lC9hjcz7phWG-fQADjO54aH9Wg2RPrrB) сохраняет проверенные GitHub Release записи самого проекта. Три ранее проблемных APK Projectivy 92, Task Killer 43 и PandaVision 1001 помещены в карантин по конкретным хэшам: повторное скачивание этих файлов не возвращает их в каталог. Оригиналы на диске не удаляются.

Встроенный каталог подписанного APK — снимок на момент сборки. После публикации онлайн-каталог содержит хэши выпущенных файлов; пересборка бинарника только ради его собственного хэша не требуется.

## Сборка из исходников

Нужны совместимый с Gradle 9.6 JDK (17+), Android SDK Platform 37.0 и Build Tools 36.0.0. Android Studio предоставляет JDK; локально использован её bundled JBR.

```powershell
./scripts/build.ps1
```

Собираются оба debug APK, Android-тесты, тесты лаунчера и lint. Выходы: `app/build/outputs/apk/debug/app-debug.apk` и `launcher/app/build/outputs/apk/debug/launcher-debug.apk`. Debug-пакеты имеют суффикс `.debug`.

Для подписанного выпуска владелец использует свой локальный каталог подписи с `ezch-update-release.jks`, alias `ezch-update` и `gradle.properties` с `EZCH_STORE_PASSWORD` / `EZCH_KEY_PASSWORD`:

```powershell
./scripts/build-release.ps1 -SigningProject C:\Path\To\PrivateSigning -Output ./dist/EZCH_Update_1.6.1.apk
./scripts/build-release.ps1 -Module launcher -SigningProject C:\Path\To\PrivateSigning -Output ./dist/EZCH_Launcher_0.20_USB.apk
```

Пароли передаются инструменту подписи через окружение и не сохраняются в проекте. Скрипт проверяет сертификат, метаданные и выравнивание APK. Приватные ключи и личные переписки не входят в репозиторий.

Сертификат текущих выпусков SHA-256: `ea0e9a1aad77b1fb42f32644a7386131ceed43e07464dcde22754691e70cc602`.

Синхронизация запускается каждые 15 минут. Список, APK, подпись и контрольные суммы проверяются до замены каталога. Если публичная разметка Drive изменится, появятся вложенные папки или потребуется пагинация (50+ файлов), синхронизация сохраняет предыдущий каталог и сообщает об ошибке; сокращённый список не публикуется.
