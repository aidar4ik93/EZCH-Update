# EZCH Update

Приложение для установки и обновления APK на Android 9+, Android TV и Google TV. Версия **1.4**, package `com.example.ezchupdate`, versionCode **14**.

[Скачать подписанный APK](https://github.com/aidar4ik93/EZCH-Update/releases/tag/v1.4.0) · [План проекта](PROJECT_PLAN.md) · [Проверки](TESTING.md)

## Использование

1. Установите EZCH Update и откройте его в меню ТВ.
2. Перемещайтесь стрелками пульта; нажимайте ОК для выбора приложений.
3. Нажмите «Установить выбранные». При первом использовании Android откроет разрешение установки из этого источника. После возвращения очередь продолжится, если разрешение предоставлено.
4. Подтверждайте каждую установку в системном окне Android. Панель снизу показывает текущий APK, реальные загруженные байты, прогресс и отмену очереди.

Статусы определяются установленным versionCode: отсутствующее приложение — «Установить», более старая версия — «Обновление», актуальная или более новая — «Установлено». Уже установленные актуальные приложения не добавляются в очередь.

Каталог сохраняется локально; без сети доступен сохранённый или встроенный список. Скачивание APK требует сети. Ошибки установки перечисляются в итогах; неудавшиеся приложения остаются выбранными для повторной попытки. При обновлении самого EZCH он устанавливается последним.

## Сборка

Нужны JDK 17+ и Android SDK Platform 37.0 / Build Tools 36.0.0. Android Studio содержит подходящий JDK.

```powershell
./scripts/build.ps1
```

Скрипт запускает сборку debug APK, JVM-тесты, компиляцию Android-тестов и lint. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

Для подписанного release настройте переменные окружения `EZCH_KEYSTORE_FILE`, `EZCH_STORE_PASSWORD`, `EZCH_KEY_ALIAS`, `EZCH_KEY_PASSWORD`, затем:

```powershell
./scripts/build.ps1 -Release
```

Файл: `app/build/outputs/apk/release/app-release.apk`. Приватный ключ и пароли не хранятся в репозитории. Для обновления поверх существующей версии нужен тот же ключ подписи. Debug APK подписан тестовым ключом и не заменяет установленный release.

Проверка на подключённом тестовом Android TV:

```powershell
./gradlew.bat :app:connectedDebugAndroidTest
```

## Каталог

`apps.json` загружается из main этого репозитория. Его копия в `app/src/main/assets/apps.json` используется при первом запуске без сети; обе копии должны совпадать.

- `name`, `packageName`, `versionCode`, `versionName` соответствуют реальному APK.
- `apkUrl` — HTTPS-ссылка; для общей папки Яндекс Диска `apkPath` — точный путь файла.
- `sha256` и `sizeBytes` проверяют содержимое APK до установки.
- `iconUrl` — необязательная HTTPS-ссылка. Иконки текущих приложений включены в APK.

```powershell
./scripts/validate-apps-json.ps1
./scripts/audit-catalog-sources.ps1 -RemoteCheck
```

Проверка локальных APK также сравнивает Android manifest; параметры описаны в `scripts/audit-catalog-sources.ps1`. Изменять каталог можно без пересборки приложения. Новые приложения с launcher доступны обнаружению через Android package queries.

APK EZCH в каталоге ссылается на GitHub Release; SHA-256 самого выпуска опубликован отдельным файлом, чтобы встроенный каталог не зависел от хеша содержащего его APK.

## Установка и прежняя проблема Play Защиты

Перед установкой проверяются размер, контрольная сумма, packageName, versionCode, minSdk, архитектура процессора и совместимость подписи с установленной версией. Android завершает проверку подписи APK и установку. Каждая установка явно требует системного согласия; скрытая установка и отключение Play Защиты не используются.

Готовый release подписан прежним ключом EZCH. Это сохраняет совместимость обновления, но само по себе не гарантирует отсутствие предупреждения Google Play Защиты. Для этой проверки требуется установить подписанный APK на физическое устройство с включённой защитой. Результаты проведённых проверок и границы проверки перечислены в [TESTING.md](TESTING.md).
