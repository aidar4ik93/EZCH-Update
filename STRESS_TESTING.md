# Launcher 0.20 и Update 1.6.2 — 9 октября 2026

## Исправления

- Магазин показывает проверенный локальный каталог до ответа сети; выбор доступен во время фоновой проверки.
- Автоматическая проверка при возврате на экран ограничена интервалом в пять минут. Ручная проверка остаётся доступна после завершения текущего запроса.
- После установки открывается лаунчер требуемой версии. Старая установленная версия больше не удовлетворяет условию завершения обновления.
- Декодирование значков установленных приложений выполняется вне основного потока.
- Анимация ореола карточки считывается на этапе рисования. Изменения координат плиток при прокрутке не вызывают пересборку всего рабочего стола.
- Карточки магазина получили скругления 16 dp, заголовок показывает выбор и фоновую проверку, меню удержания уменьшено до 280 dp и стало прозрачнее.

## Автоматические проверки

Android TV API 34: **29 тестов Launcher + 23 теста Update**, без ошибок и пропусков. Среди них установка с подтверждением Android и финальным результатом, системная отмена, восстановление очереди, проверка размера, пакета, версии и сертификата APK, отказ для повреждённого файла.

В каждом магазине: задержанный сетевой ответ, 2001 переключение выбора, 100 повторных запросов во время загрузки и 100 автоматических запросов после неё. Проверены сохранение выбора и отсутствие дублирования запросов, работа с повреждённым кэшем без сети, запрет открытия старого лаунчера по незавершённой настройке.

Лаунчер: 30 открытий меню удержанием, переход на «Скрыть», закрытие по Назад и проверка неизменности рабочего стола. Проверены повторные перемещения, фактическое скрытие, остаточные события удержания и сохранение фокуса. Прежние сценарии USB, источников и освобождения ресурсов видеообоев прошли.

JVM: **49 тестов**, 48 прошли, один Windows symlink-тест пропущен. В том числе 20 000 смешанных изменений рабочего стола с 1000 приложений: перемещение, скрытие, восстановление, перестановка строк и отмена; идентичность приложений и структура сохраняются. Lint обоих приложений: 0 ошибок.

## Воспроизведение нагрузки на готовых APK

Установите оба подписанных APK на тестовый Android TV. Выполните:

```powershell
./scripts/stress-tv-navigation.ps1 -Device emulator-5556 -ReportDirectory ./verification/navigation
```

Сценарий выполняет пять холодных запусков каждого приложения и по 3000 событий навигации пультом с интервалом 20 мс и фиксированным seed 9020. Он проверяет отчёт Android Monkey на завершение и отсутствие CRASH/ANR, сохраняет статистику кадров, память и снимок экрана. Случайное подтверждение установки, удаление файлов и изменение системных настроек не входят в эту нагрузку: установка и отмена проверяются отдельными контролируемыми сценариями выше.

## Результат нагрузки на подписанных APK

Оба APK установлены поверх прежних выпусков на API 34: Update 1.6.2 (23), Launcher 0.20-USB (21). Каждый завершил 3000 событий Android Monkey, CRASH и ANR в отчётах отсутствуют. Дополнительно выполнено по пять холодных запусков без ошибок. После нагрузки визуально проверены магазин и меню удержания.

PSS Update: 71 423 → 67 515 КБ, Launcher: 112 424 → 69 665 КБ. Эти отдельные снимки памяти не доказывают отсутствие долгосрочных утечек.

На программном рендерере SwiftShader без Vulkan получено 54,88% janky frames в Update и 50,48% в Launcher, медиана кадра 48 мс у обоих. Плавность на этой конфигурации не соответствует 60 кадрам/с. Время холодного запуска Activity: Update 2,97–3,72 с, Launcher 1,70–2,17 с. Прежние контрольные запуски сделаны при другой конфигурации эмулятора и фоновой сборке; сравнивать их как процент ускорения некорректно. Задержка появления каталога при медленной сети устраняется показом локального списка, что отдельно проверено контролируемым тестом.

## Пределы проверки

Физическая приставка 192.168.1.139:5555 недоступна во время этой проверки. Новые версии проверяются на эмуляторе; результаты не являются замером скорости на Amazon AFTKM. Холодный запуск Activity не измеряет завершение загрузки сетевого каталога. Из этих результатов нельзя выводить процент ускорения или отсутствие всех возможных ошибок.

После завершения автоматических тестов первый экземпляр эмулятора завершил графический процесс с ошибками ColorBuffer. Для нагрузки запущен новый экземпляр с отключённым Vulkan. Это отдельно от результатов Android-тестов приложений. Прежние ограничения облачных проверок API 33 описаны в TESTING.md и не объявляются исправленными данным выпуском.
