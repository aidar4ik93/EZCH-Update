# Проверки EZCH Update 1.4

## Автоматические проверки

Локально прошли 26 JVM-тестов, 16 Android-тестов на Google TV API 33 и Android lint. Скрипт проверки XML-отчётов подтверждает, что Android-тесты действительно выполнены, без пропусков и ошибок.

JVM-тесты проверяют очередь (самообновление последним, сохранение предыдущих ошибок, чужой результат не двигает очередь), HTTPS-перенаправления, версии и структуру каталога, SHA-256, размеры, подписи, обрыв и отмену загрузки, HTML вместо APK и офлайн-выбор источника.

Android-тесты выполняются на Google TV API 33 (Android 13), 1920×1080 px / 960×540 dp. Они проверяют статусы установленных/отсутствующих/более новых приложений, начальный фокус, стрелки и ОК, кнопки установки/обновления/отмены/подтверждения, ошибки и иконки. Тесты установщика используют настоящие Android preferences и принадлежащие тесту пустые PackageInstaller sessions: восстановление, сохранение системного Intent, точное совпадение идентификатора, отмену и отказ записи при заполненном хранилище.

Шесть проверок APK вызывают код установщика с настоящими подписанными файлами: корректная подпись, совместимая подпись обновления, совместимость старого API, отказ неподписанному APK и APK с другим ключом. Это защищает от выявленного поведения Android 13, где чтение подписи архива требует одновременно флагов `GET_SIGNATURES` и `GET_SIGNING_CERTIFICATES`.

```powershell
./scripts/build.ps1
./gradlew.bat :app:connectedDebugAndroidTest
./scripts/verify-android-test-results.ps1
```

GitHub Actions повторяет сборку, JVM-тесты, проверку каталога и lint; отдельные задания запускают Android-тесты на Android TV API 28 и Google TV API 33. Отчёты и debug APK сохраняются в artifacts. Локально Android-тесты запускаются на подключённом эмуляторе или тестовом устройстве.

## Проверка источников

18 сторонних APK проверены по фактическим Android manifests: packageName, versionCode и versionName совпадают с каталогом. SHA-256 и размер локальных файлов совпадают с метаданными общедоступной папки Яндекс Диска; ссылки скачивания отвечают HTTP 200.

После добавления пользователем Lift 0.2.45 проверен и возвращён в каталог с настоящей иконкой. Прежняя ссылка EZCH 1.3 возвращает 404 и заменена выпуском EZCH 1.4 на GitHub, подписанным прежним ключом.

## Сквозная проверка подписанного выпуска

На Google TV API 33 установлен подписанный EZCH 1.4 поверх оригинального EZCH 1.2. SHA-256 сертификата совпадает: `ea0e9a1aad77b1fb42f32644a7386131ceed43e07464dcde22754691e70cc602`.

В EZCH предоставлено разрешение установки из этого источника. APK Task Killer TV скачан из Яндекс Диска, проверен и передан системному установщику. После согласия в окне Android установлены package `jp.snowlife01.android.appkiller2`, versionCode 43, versionName 4.0.2; EZCH показал «Установлено: 1 из 1. Очередь завершена». Отмена очереди RuStore на этапе ожидания подтверждения также проверена: незавершённый выбор сохранён.

В очереди из KinoTrend и SerialTrend отклонена первая установка, затем подтверждена вторая. Android установил `ru.twicker.serialtrend`, versionCode 1, versionName 0.0.5a. Итог EZCH сохранил отказ: «Установлено: 1 из 2. Ошибки: KinoTrend: Установка отменена пользователем или Android». KinoTrend остался выбранным для повторной попытки.

## Проверка физических устройств перед широким распространением

- Android 9 и современный Google TV: запуск, пульт, видимость установленных версий.
- Разрешение установки: отказ, предоставление, возвращение в приложение.
- С включённой Google Play Защитой: установка готового подписанного EZCH 1.4 и приложение из каталога. Результат защиты определяется устройством и сервисами Google; эмулятор его не подтверждает.
- Обновление поверх версии 1.2/1.3 без удаления настроек.
- Два приложения в очереди: согласие, отказ на одном APK, следующий APK и точный итог.
- Отмена скачивания и системного подтверждения; отключение сети; нехватка памяти.
- Убийство процесса во время скачивания/подтверждения: выбор и сеанс восстанавливаются без ложного сообщения об успехе.

Поддерживаемый minimum SDK — API 28. Проверки на эмуляторе API 33 не означают физическую проверку каждого устройства Android 9+.
