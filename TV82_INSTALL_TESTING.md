## Причина блокировки Update

Системное окно: «Вредоносное приложение заблокировано», «Это приложение может устанавливать потенциально опасные приложения без вашего разрешения». Callback: `INSTALL_FAILED_VERIFICATION_FAILURE: Install not allowed`. Установщик не зависает и правильно учитывает отказ.

Подпись APK 1.6.2 проверена штатным apksigner: схемы v2 и v3 валидны. SHA-256 APK: `9d0f2c1043d3be4a7426065acf3a7b4e3bde4af9721d4315f9ab4cd334fe29ac`. SHA-256 сертификата: `ea0e9a1aad77b1fb42f32644a7386131ceed43e07464dcde22754691e70cc602`.

В манифесте Update заявлены INTERNET и REQUEST_INSTALL_PACKAGES. Установка использует PackageInstaller; на API 31+ явно требует USER_ACTION_REQUIRED. Системное подтверждение открывает только активный экран приложения. Эти проверки не доказывают ошибочность классификации Google. Автоматическая установка без подтверждения не добавлялась.

Play Защита и системные проверки не отключались. Настройка package_verifier_enable после тестов: 1. Изменение подписи или пакета для обхода проверки не выполнялось.

На физической приставке проверены запуск подписанной сборки, получение актуального каталога, отмена и успешная повторная установка. Длинное сообщение в общей сводке ограничено двумя строками; полный исходный текст сохранён в состоянии очереди. Исправление также перенесено в исходники встроенного магазина; установленный Launcher 0.20 не пересобирался в этом выпуске.
