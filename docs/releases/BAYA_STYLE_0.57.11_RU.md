## Реализация

RussianStress обрабатывает все русские ответы: контекстные правила и модель для омографов, затем ngram-модель для слов вне словаря исключений. Это общий обработчик, а не список исправлений только для демонстрационной фразы. Сохранены словарь исключений, явные ударения на входе обработчика и буква «ё».

В BayaEngine перенесён согласованный образец: темп 0.87, отдельная интонация вопроса и восклицания, мягкие смысловые акценты, небольшое удлинение окончаний слов. Полный PCM модели не обрезается. После предложений добавляется короткая пауза. Синтез работает локально после загрузки моделей; в новых моделях проверяются размер и SHA-256.

Голосовой APK — 16 386 671 байт, лаунчер — 82 029 074 байта. Модели хранятся отдельно: всего около 308 МБ; ранее загруженные четыре файла не скачивались повторно. Обновление добавило две модели ударений.

## Найденные и исправленные проблемы

Первый прогон выявил неподдерживаемый Android флаг UNICODE_CHARACTER_CLASS; флаг удалён, все правила успешно проверены. Следующий прогон обнаружил SIGBUS/BUS_ADRALN при загрузке контекстной модели в ONNX Runtime на ARMv7. Для этой модели отключены оптимизации графа (NO_OPT). После изменения полный прогон 87 фраз завершился успешно за 4699 мс. Исходные сбои сохранены в homatics-stress-parity-final.txt и stress-native-tombstone.txt; они не скрыты за итоговым PASS.

Сходные сбои ARMv7 обсуждаются в первичном трекере ONNX Runtime: https://github.com/microsoft/onnxruntime/issues/26772 . Выбор NO_OPT проверен непосредственно на этой приставке, а не принят только по сообщению из трекера.
